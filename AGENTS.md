# Instrucciones para agentes de IA

Este repositorio es la fuente de continuidad operativa de la tesis 360°. Antes de modificarlo, sigue este orden:

1. Lee `seguimiento/INSTRUCCIONES_ACTUALIZACION_IA.md` completo.
2. Lee `seguimiento/ESTADO_ACTUAL.md`.
3. Lee el informe de avance indicado por el usuario en `actualizaciones/`, si existe.
4. Lee únicamente las fases, decisiones, hitos o fuentes afectadas.
5. Consulta `PLAN_MAESTRO_TRABAJO_TESIS_360.md` cuando necesites confirmar el alcance o la secuencia general.

## Fuentes de verdad

| Información | Ruta |
|---|---|
| Estado, fase, próxima tarea y bloqueos | `seguimiento/ESTADO_ACTUAL.md` |
| Tareas | `seguimiento/fases/*.md` |
| Hitos | `seguimiento/hitos/*.md` |
| Decisiones | `seguimiento/decisiones/*.md` |
| Historial | `seguimiento/log/*.md` |
| Bibliografía y fichas | `bibliografia/fuentes/*.md` |
| Informes originales recibidos | `actualizaciones/YYYY/*.md` |
| Estrategia general | `PLAN_MAESTRO_TRABAJO_TESIS_360.md` |
| Comprensión académica | `DOCUMENTO_MAESTRO_TESIS_360_GESTION_INFORMACION_VISUAL.md`, cuando exista |

## Reglas no negociables

- No inventes avances, fechas, fuentes, decisiones, entregables ni resultados.
- No marques una tarea como `terminada` sin un entregable verificable.
- Distingue hechos, propuestas y decisiones confirmadas.
- Conserva los informes recibidos; son evidencia de entrada, no la fuente operativa final.
- No publiques PDFs restringidos, contactos ni datos personales.
- No cambies una decisión académica solo para acomodar la web.
- Registra contradicciones o ambigüedades como pendientes; no las resuelvas silenciosamente.
- Ejecuta `npm run validate` y `npm run build` antes de cerrar una actualización.

Al terminar, informa: archivos modificados, tareas que cambiaron de estado, decisiones registradas, siguiente tarea resultante y cualquier duda no resuelta.
