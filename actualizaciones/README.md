# Informes de avance recibidos

Guarda aquí los Markdown producidos en ChatGPT u otra herramienta antes de pedir a un agente que actualice el seguimiento.

Convención:

```text
actualizaciones/YYYY/YYYY-MM-DD-descripcion-breve.md
```

El agente debe preservar el cuerpo original, añadir el estado de procesamiento al frontmatter y distribuir la información confirmada entre las fuentes de verdad. Consulta `seguimiento/INSTRUCCIONES_ACTUALIZACION_IA.md`.

Ejemplo de solicitud:

```text
Lee AGENTS.md y procesa el informe
actualizaciones/2026/2026-08-23-avance-bibliografia.md.
Actualiza las fuentes de verdad, valida el repositorio y resume los cambios.
```
