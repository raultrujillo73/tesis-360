# Biblioteca bibliográfica

Cada archivo de `fuentes/` reúne los metadatos y la ficha analítica de una fuente. La matriz de la web se genera automáticamente a partir del frontmatter.

## Flujo de una fuente

1. Crear el archivo desde `plantillas/FUENTE_BIBLIOGRAFICA.md`.
2. Completar metadatos verificables y enlaces legítimos.
3. Cambiar `download_status` cuando el texto esté disponible localmente.
4. Cambiar `reading_status` durante la lectura.
5. Completar la ficha, citas de trabajo y límites de uso.
6. Marcar `analysis_status: terminada` solo cuando la ficha sea trazable.

Los PDFs no públicos no se versionan. `archivos-locales/` está ignorado por Git.
